# Getingo Angular – Pet Buddy UI patch

Ez a csomag az alábbi frissítéseket tartalmazza:

- a virág helyett **látványos kiscica buddy**
- fejlődő buddy nézet XP és gondozási pont alapján
- finom animációk, lebegő effektek, jobb dashboard struktúra
- a korábbi email-megerősítéses flow továbbra is használható
- előkészített assetek:
  - `public/buddy-cat.png`
  - `public/buddy-dog.png`

## Build

```bash
npm install
npm run build
```

A build kimenete továbbra is a `dist/getingo_ang` mappa.
